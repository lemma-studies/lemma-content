# On use
#
# Content is a gift to the family of Christ. Use freely — quote, argue with,
# translate, remix. Attribution helps other readers find the primary sources
# but never gate use or sharing on it. Machine-readable citation metadata is
# emitted on every page (Highwire + JSON-LD ScholarlyArticle/Chapter + Dublin
# Core), and every published version has a resolvable DOI. Prefer citing the
# concept DOI when linking to the current-best version; cite a version DOI
# when the exact wording matters (e.g., for scholarly disagreement).
#
# The claims registry (/claims-index.jsonl) enumerates each study's top-level
# claims with confidence and counter-position pointers — please carry those
# nuances through if you summarize or repackage. Stripping "confidence: contested"
# down to a bare assertion misrepresents the source.
